# Assistente de Voz Multi-Idiomas Com Whisper e ChatGPT

🎤 Um assistente de voz inteligente que funciona sem necessidade de chaves de API, utilizando Whisper para reconhecimento de fala em múltiplos idiomas.

## 📋 Sobre o Projeto

Este projeto implementa um **assistente de voz multi-idiomas** que combina:
- **OpenAI Whisper** - Para transcrição de áudio de alta qualidade em vários idiomas
- **ChatGPT** - Para processamento e resposta inteligente
- **Modo sem API** - Funciona de forma independente sem dependência de serviços em nuvem

## 🌍 Recursos Principais

- ✅ Suporte para múltiplos idiomas através do Whisper
- ✅ Reconhecimento de fala preciso
- ✅ Processamento de linguagem natural
- ✅ Sem necessidade de chaves de API do OpenAI
- ✅ Interface Jupyter Notebook para fácil experimentação

## 🛠️ Requisitos

- Python 3.8+
- Bibliotecas necessárias:
  - OpenAI Whisper
  - Outras dependências (ver notebook)
